# Публичный экран палаты

URL: **`/room`** или **`/room/:monitorId`**

Компонент: `frontend/src/pages/RoomDisplayPage.tsx`  
Стили v2: `frontend/src/pages/RoomDisplayPageV2.css`  
Legacy: `?legacy=1` → `RoomDisplayPage.css` + `BedSchematic`

**Без авторизации** (при `ALLOW_PUBLIC_ROOM_DISPLAY=True` на backend).

---

## Назначение

Fullscreen-дисплей на мониторе в палате. Показывает:

- список коек палаты (из 1С);
- витальные показатели с BLE-браслета (если пациент занимает койку и привязан MAC);
- статусы пациента (цветные флажки);
- атмосферу палаты (температура, влажность, давление).

Не показывает: назначения, формы, редактирование, модалки.

---

## Выбор палаты

| Режим | Поведение |
|-------|-----------|
| `/room` | Селектор палаты в шапке (если несколько) |
| `/room/:monitorId` | Палата привязана к ID монитора (из конфигурации комнат) |

Койки берутся из `GET /rooms/` → `activeRoom.beds`, сортировка по номеру койки.

## Метрики браслета (5 плиток)

Порядок в сетке 2×2 + одна внизу:

| # | Метрика | Иконка | Ключ API |
|---|---------|--------|----------|
| 1 | Температура | `temp-chel.png` | `temp`, `temperature` |
| 2 | Пульс | `pulse.png` | `pulse`, `hr`, `bpm` |
| 3 | Арт. давление | `art-davl.png` | `press`, `bp` |
| 4 | SpO₂ | `spo2.png` | `spo2`, `sp_o2` |
| 5 | Сон | `sleep.png` | `sleep` |

Свободная койка: все значения «—», карточки и метрики приглушены.

Нормализация ключей: `utils/monitoringDisplay.ts` → `normalizeMetricKey`, `unwrapMetric`.

---

## Статусы пациента (флажки)

Колонка слева от аватара, **22 px от верха** блока пациента.

Порядок сверху вниз:

1. Зелёный (диета)
2. Красный (аллергия)
3. Оранжевый (инфекция)
4. Жёлтый (риск падения)
5. Белый (всё в порядке)

Показываются только **активные** флаги (`activePatientFlagStatuses`). Флаги «выглядывают» из-за левого края аватара (`left: -24px`).

## Атмосфера (футер)

Три карточки в ряд:

| Показатель | Иконка | Норма (подпись) |
|------------|--------|-----------------|
| Температура | `temperatura.png` | 22–26 °C |
| Влажность | `vlajnost.png` | 40–60 % |
| Давление | `davlenie.png` | 1000–1025 мм |

Данные: `dashboard.atmosphere` с backend (`monitor_zone` палаты → Monitoring API).

При ошибке: `dashboard.atmosphere_error` под футером.

---

## Опрос данных

| Параметр | Значение |
|----------|----------|
| `POLL_MS` | 3000 мс — `getRooms()` + `getMonitoringDashboard(roomId)` |
| `PAGE_RELOAD_MS` | 15 мин — полная перезагрузка страницы |

Индикатор связи в шапке — по успешности последнего запроса.

---

## API

Без JWT (публичный режим):

```
GET /api/v1/rooms/
GET /api/v1/monitoring/dashboard?room_id={id}
```

Опционально `GET /api/v1/patients/` — для legacy layout.

---

## Legacy-режим

`http://localhost:3000/room?legacy=1`

- Тёмная тема
- `BedSchematic` вместо v2-карточек
- Атмосфера в боковой колонке (4 показателя включая CO₂)
- Сохранён для обратной совместимости со старыми мониторами
